## Selected Projects

### 1. Solar Module Logistics & Packing Control

- **Problem**: 머신비전 검사, 포장 설비, 무인 반송 장비 간의 복잡한 인터록과 대기시간 발생
- **Role**: PLC 시퀀스 설계, HMI 구성, 통신 연동, 시운전 및 양산 안정화
- **Tech**: Mitsubishi PLC, GX Works2, CC-Link, TCP/IP, LGV Handshake
- **Impact**: 설비 대기 지연과 인터록 병목을 개선하고 안정적인 양산 이관 지원

### 2. Dynamic Stocker Control & High Availability

- **Problem**: 고정 규칙 기반 입출고로 인해 특정 포트와 스토리지에 작업이 집중되는 문제
- **Role**: 설비 상태, 우선순위, 이동거리와 작업 Queue를 반영한 동적 입출고 로직 설계
- **Tech**: C#, MySQL, REST API, PowerShell, HA Architecture
- **Impact**: 물류 분산 처리와 장애 대응이 가능한 스토커 제어 구조 구현

### 3. Enterprise RAG Knowledge Search

- **Problem**: 안전, 환경, 인사 및 기술 규범 문서가 분산되어 필요한 정보를 빠르게 찾기 어려운 문제
- **Role**: PDF 문서 전처리, Chunking, Embedding, Vector Search 및 로컬 LLM 응답 파이프라인 설계
- **Tech**: Python, LangChain, Chroma, Ollama, Qwen, MySQL
- **Status**: In Progress

### 4. Machine Learning Demand Forecasting

- **Problem**: 일별 이용 인원 변동으로 인해 운영 수요를 사전에 정확히 예측하기 어려운 문제
- **Role**: 인원, 메뉴, 출근 데이터의 분석 테이블 설계 및 일일 예측/메일링 서비스 구현
- **Tech**: Python, LightGBM, MySQL, Windows Server
- **Impact**: 수작업 예측을 데이터 기반 일일 자동 예측 프로세스로 전환

### 5. Server Monitoring Platform

- **Problem**: 약 500대의 생산/설계 서버를 수동 점검해 장애를 사전에 감지하기 어려운 문제
- **Role**: Agentless 수집 데몬, 데이터 저장, 대시보드 및 장애 리포트 자동화 개발
- **Tech**: C#, .NET Framework, WMI, MySQL, Grafana, EWS API, Windows Service
- **Impact**: 서버 리소스를 분당 2회 수집하는 실시간 관제 체계를 구축하고 연간 약 5천만 원의 운영 비용 절감에 기여

### 6. Parallel Analysis Server Scheduler

- **Problem**: 다중 사용자의 동시 작업으로 인한 메모리 고갈과 고가 서버 교체 필요성
- **Role**: Job Queue, 가중치, 메모리 임계치 기반 비동기 실행 제어 설계
- **Tech**: CentOS, Bash, C#, IPC
- **Impact**: 기존 서버 자원의 활용도를 높여 신규 인프라 투자 비용 절감에 기여
